# Test Project (`Mam123smile/test-project`)

โปรเจกต์เริ่มต้นสำหรับทดสอบการใช้งาน Git และ GitHub

## โครงสร้างโปรเจกต์ (Project Structure)

```text
test-project/
├── .gitignore      # กำหนดไฟล์ที่ไม่ต้องการให้ Git ติดตาม (เช่น .DS_Store, .env, node_modules)
├── README.md       # เอกสารอธิบายโปรเจกต์และการใช้งานเบื้องต้น
└── index.html      # หน้าเว็บตัวอย่างสำหรับทดสอบโปรเจกต์
```

## คำสั่ง Git พื้นฐานที่ใช้บ่อย

```bash
# 1. เช็กสถานะไฟล์ที่มีการแก้ไข
git status

# 2. เพิ่มไฟล์เข้าสู่ Staging Area
git add .

# 3. บันทึกการเปลี่ยนแปลง (Commit)
git commit -m "อธิบายสิ่งที่แก้ไข"

# 4. อัปโหลดโค้ดขึ้น GitHub (Push)
git push origin main

# 5. ดึงโค้ดล่าสุดจาก GitHub ลงมาที่เครื่อง (Pull)
git pull origin main
```
