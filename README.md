# สมุดสะสมของเล่นหน้าโรงเรียนยุค 90s (พ.ศ. 2533–2542) — `Mam123smile/test-project`

เว็บกึ่งพิพิธภัณฑ์และร้านค้าของเล่นหน้าโรงเรียน & ของแถมซองขนมยุค 90s ดีไซน์ในรูปแบบ **สมุดสะสมสติ๊กเกอร์ไทม์ไลน์ พ.ศ. 2533–2542 (ค.ศ. 1990–1999)**

🌐 **เข้าชมเว็บไซต์ออนไลน์ (GitHub Pages):** https://mam123smile.github.io/test-project/

## ฟีเจอร์หลัก (Features)

1. **ไทม์ไลน์สมุดสะสมสติ๊กเกอร์ พ.ศ. 2533–2542:**
   - จัดแสดงของเล่นหน้าโรงเรียนและของแถมซองขนม 8 ชิ้นระดับตำนาน (ลูกแก้วโบราณ, ตุ๊กตากระดาษ, เป่ากบยางวง, สมุดสติ๊กเกอร์/การ์ดพลัง, เหรียญทาโซ่, ดาวเรืองแสง, ลูกอมเป๊าะแป๊ะ/หมากฝรั่งนกแก้ว, แผงฉลากจับเบอร์)
   - กดเปิดอ่าน **"บันทึกความทรงจำหน้าโรงเรียน"** และ **"กติกาวิธีเล่นสมัยประถม"** รายชิ้น
2. **ระบบสมุดปั๊มสติ๊กเกอร์ (`localStorage`):**
   - เมื่อกดเปิดอ่านประวัติของเล่นแต่ละปี พ.ศ. จะได้รับตราปั๊มสะสมลงสมุดอัตโนมัติ
   - สะสมครบทั้ง 8 ปี พ.ศ. รับส่วนลดพิเศษ **50 บาท** ในตะกร้าสินค้าทันที
3. **แผงฉลากจับเบอร์หน้าโรงเรียน:**
   - กดสุ่มฉีกเบอร์ฉลากลุ้นคูปองส่วนลดพิเศษนำไปใช้ลดราคาในตะกร้าได้จริง
4. **ระบบตะกร้าสินค้าและชำระเงินครบวงจร:**
   - คำนวณราคาหักส่วนลดจากสมุดสะสมและฉลากนำโชคอัตโนมัติ
   - ฟอร์มกรอกชื่อ-เบอร์โทร-ที่อยู่จัดส่ง พร้อมตัวเลือกชำระเงินผ่าน **PromptPay QR Code** หรือ **เก็บเงินปลายทาง (COD)** และออกตั๋วใบเสร็จยุค 90s
5. **โทนสียุค 90s 2 สไตล์:**
   - สลับได้ระหว่างโหมด **สมุดสติ๊กเกอร์ยุค 90s (Warm Sticker Album)** และ **90s Cyber Neon**
